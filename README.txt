# ポロを。こっそりおでかけ — v10 見回りとひらめき

ZIP名は **Poro_Escape_v10_fixed.zip**、ゲーム本体は **Poro_Escape_v10_20260921.html** です。起動後、左上に **v10** と出れば今回の版です。

## 今回の変更

- **謎を読んでいる間も追跡が続きます。** 書斎とリビングには見回りロボがいます。視野の扇形を避け、家具で視線を切りましょう。見つかって近づかれると捕獲予告が出ます。「回避」で離れる猶予があります。
- **調べる画面から、そのまま逃げられます。** 移動パッドを動かすか回避するとパネルが閉じます。集めたメモ、途中の本の並び、時計、スイッチの状態は残ります。メモを持ち歩いて考えられますが、仕掛けの操作には近くへ戻る必要があります。
- **覚えた答えだけでは解けない構成にしました。** 通常の新しい冒険では、本の条件・時計・配線・初期状態・見回り順序が変わります。書斎では3枚、リビングでは2枚の手掛かりを集めます。設定の「同じ合言葉で遊ぶ」をオンにすれば、同じ条件で再挑戦できます。部屋の再挑戦は元の条件を保ちます。
- **仕掛けが、逃げ方にも影響します。** 明かりを減らすとロボの視野が短くなり、テレビの音は見回りを引き寄せます。換気扇は走る足音を隠します。配線ボタンはつながる機器すべてを反転するので、目標の状態と安全の両方を考えます。
- **「しのび足」と「音で誘う」を追加しました。** 誘導は各部屋3回、再使用まで9秒。普通に走る足音や、間違えた操作の音にも見回りが反応します。
- 家具の一部が欠ける描画不具合、家具の角で経路が詰まるケースも修正。警戒表示、捕獲の予告音、回路に連動する換気扇と照明、物理的なメモを追加しました。

開始後は最初の操作まで敵も時間も待機します。これはメニューではありません。別のアプリへ移った間と、明示的な一時停止では時間を止めます。指の動きで設定や一時停止が勝手に開かない入力処理は引き継いでいます。

### 公開済みのゲームを更新する

1. ZIPを解凍し、**index.html と Poro_Escape_v10_20260921.html の両方**を、既存リポジトリの公開フォルダー直下へアップロードします。ZIPそのものはアップロードしません。
2. Commit changesで保存し、ActionsのPages公開処理が成功するまで待ちます。
3. 既存ゲームURLの末尾へ **Poro_Escape_v10_20260921.html** を付けて開きます。例：`https://あなたのGitHubユーザー名.github.io/poro-game/Poro_Escape_v10_20260921.html`。
4. 左上の **v10** を確認してください。この新しいファイル名のURLなら、古いindex.htmlが残っていても今回のゲームを指定できます。

`index.html` は今回の名前付きHTMLへ移動する入口です。合言葉と難易度のURLパラメーターも引き継ぎます。ゲーム本体にはプログラム・3D・木目と布・原画比較画像・音を内蔵しています。Blenderやサーバーの準備は不要です。

## GitHub Pagesで公開する

1. 自分のブラウザーでGitHubにログインします。アカウントがない場合はGitHubで作成します。
2. **New repository** を選び、名前を `poro-game`、公開範囲を **Public**、**Add README** を有効にして作成します。
3. パッケージを解凍します。作成したリポジトリの **Add file → Upload files** で、中の **index.html と Poro_Escape_v10_20260921.html の両方**をアップロードし、**Commit changes** で保存します。ZIPのままアップロードしないでください。`index.html` がリポジトリの一番上に見える状態にします。
4. **Settings → Pages** を開きます。**Build and deployment → Source** を **Deploy from a branch**、**Branch** を **main**（別名の場合はファイルを置いたブランチ）、フォルダーを **/(root)** にして **Save** を押します。
5. 公開処理が完了したら同じ画面の **Visit site** を押します。初回の反映には最大10分ほどかかる場合があります。表示されたURLを友だちへ渡します。

公開URLの形式は `https://あなたのGitHubユーザー名.github.io/poro-game/` です。この文字列は形式の例で、すでに作成済みのURLではありません。

公開ページでは「友だちに渡す」から、同じ合言葉・難易度のリンクを共有できます。受け取ったリンクの合言葉は固定されます。スマホの共有機能が使えない場合はクリップボードへコピーします。

更新時も入口の `index.html` と版名付きのゲーム本体を両方配置します。通常の公開URLからは新しい本体へ移動します。今回の版を指定して共有する場合は、版名付きHTMLのURLを使えます。

## スマホで遊ぶ

- 公開後のHTTPSのURLをSafariまたはChromeで開きます。ファイルアプリ内のHTMLプレビューでは正常に遊べない場合があります。
- 左のエリアを好きな位置からドラッグして移動。指を少しだけ動かすとゆっくり、離すとすぐ停止。設定から感度を変えられます。水色の輪に入った敵へ通常攻撃が自動で出ます。
- 右の「回避」と3つのしぐさは直接タップします。3連撃の最後は範囲が広がり、近くの敵の弾も消します。
- 最後はお母さんから逃げる玄関。黄色い輪で止まって鍵・靴・チェーンの準備を進めます。家具の裏に隠れ、「しーっ」「待って」「音で誘う」で目をかわします。タイトルの「玄関の練習」でも始められます。
- 初めてなら難易度「さんぽ」から始められます。設定の「軽量表示」で描画負荷を下げられます。
- 記録は各端末・ブラウザー内に保存します。オンライン対戦・共通ランキングではありません。

## 公開できないとき

- **404**：`main` の一番上に、小文字の `index.html` があるか確認し、Pagesのフォルダーが `/(root)` か確認します。
- **Pagesにmainが出ない**：まだファイルが保存されていない可能性があります。アップロードの最後にCommit changesを押します。
- **公開処理の失敗**：リポジトリのActionsを開き、最新のPagesの処理結果を確認します。GitHubのメールアドレス確認が済んでいるかも確認してください。
- **古い画面が出る**：公開処理の成功後、末尾が `Poro_Escape_v10_20260921.html` のURLを開き、左上のv10を確認します。404なら名前付きHTMLが公開フォルダーにあるか確認してください。
